# Archive

Godot ignores this directory because it contains material that is not part of
the active game:

- `legacy_echoes_of_la_paz/` is an older nested Godot project retained for
  reference.
- `unimportable_source_assets/` contains source textures that Godot 4.7 cannot
  decode. Their game-ready alternatives remain in `assets/`.

Do not reference files in this directory from active scenes or scripts.
